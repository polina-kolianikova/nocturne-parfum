# NOCTURNE

Independent niche fragrance concept by Polina Koljanikova. A dark editorial product experience using generated photographic smoky glass, local Prata and Tenor Sans, and an interactive scent preference atelier.

## Run

Serve this directory over HTTP. No build, package installation, API key, runtime CDN or external font request is required. Publish the root in the dedicated GitHub Pages repository.

## Interactions

Native scroll controls the bottle's framing, scale and angle across four chapters. The same photographic cutout remains visually consistent. The light slit follows chapter progress. Fragrance stage buttons update their descriptions and selected state.

The atelier supports 27 combinations of opening, heart and base. The impression slider changes a named personal portrait and constellation. Saving downloads the actual current selection as a text file. Nothing is submitted or purchased.

## Resilience and boundaries

Transparent responsive WebP replaces the former faceted geometry and canvas label. Image decoding is requested early. There is no WebGL dependency or perpetual animation loop. Phone composition reserves space for reading; reduced motion uses still chapter states. Native inputs, visible focus, skip navigation and polite result announcements remain available.

NOCTURNE and the product are concepts. The image was generated with the built-in ChatGPT image tool. It is a photographic visual, not a freely rotatable 3D model or a physical refraction simulation. The atelier records preferences, not a manufactured fragrance formula. Font licenses are in assets/fonts.

Published browser checks use Chromium viewport emulation; physical phone and Safari results are not claimed.
